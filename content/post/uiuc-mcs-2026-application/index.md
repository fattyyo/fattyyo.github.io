## 選校策略

選校主要參考兩個資料來源：

1. **[一畝三分地](https://www.1point3acres.com/bbs/forum-82-1.html)**：上面有大量申請者自填的錄取三圍（GPA、TOEFL、GRE），可以直接查跟自己背景相近的人投了哪些學校、上了哪些，是判斷自己落點最直接的方式
2. **[Open CS Application](https://opencs.app/grade/)**：整理了各校的錄取偏好與代表性錄取案例，適合快速了解每個 program 的特性和申請難度梯度

兩個搭配使用，在確定選校名單前先查清楚，避免衝太高或保守過頭。

### 為什麼選 UIUC MCS？

- CS 四大名校之一，校友網路強大
- MCS 和 MSCS 學生**一起上課**，課程品質有保障
- 2023 年起開放第三學期 Full-Time Internship（COOP），等於多一次找工機會
- 台灣學長姐多，出國不會變孤兒

## SOP 撰寫

SOP 的核心邏輯是：**A（過去經驗）+ B（學校能給我什麼）= C（未來的自己）**

我的結構如下：

```
第一段：開場 + 為什麼要來 UIUC MCS（A+B=C 總綱）
第二段：Zyxel 實習經驗（network 測試自動化、multi-threading）
第三段：元智大學專案經驗（訂票系統、race condition、並發處理）
第四段：法國 ESME 交換的跨文化視野與技術養成
第五段：UIUC 課程客製化（點名特定教授或課程）
第六段：未來想成為什麼樣的工程師
```

**最重要的一點**：SOP 不是成就列表，要說清楚**每段經歷怎麼讓你成長、又怎麼和 UIUC 的資源扣在一起**。

## CV

CV 和 SOP 互補，SOP 說故事、CV 列數字。

幾個重要原則：
- 每一條**用動詞開頭**（Developed、Optimized、Implemented）
- 用**數字**量化影響力，例如：「減少測試時間 40%」比「加速了測試流程」有力
- 不超過兩頁
- 項目順序：Education → Work Experience → Projects → Skills

## TOEFL / GRE 備考建議

**TOEFL（個人成績：102，R28 / L30 / S23 / W21）**：
- UIUC MCS 建議 103 以上，79–102 入學後需修英文課才能畢業
- 我最終 102，差一分，入學後需補修英文課，算是小遺憾
- 口說（S）最難突破，建議多用 AI 工具模擬練習、錄音回聽
- Listening 相對好拿，多刷題、熟悉題型即可

**GRE（個人成績：323，Q170 / V153）**：
- MCS 為 optional，但附上有加分效果，建議考
- Q 滿分 170 對理工背景同學幾乎是標配，V 盡量拉到 155+
- 我的 V153 算是偏低，建議多背字彙、刷 Verbal 題型

## 推薦信建議

三封推薦信最好來自**不同面向**，我的配置是：

1. **實習主管 @ Zyxel**（最有說服力，能具體描述你在業界的技術表現）
2. **授課教授 x 2**（選對你印象深刻、能具體評價學習能力的教授）

越早確認推薦人越好，給教授足夠時間，並提供你的 CV、SOP 草稿和申請學校清單，方便他們客製化內容。

## 總結

背景不是頂尖沒關係，重點是把**有限的經歷說清楚**，讓招生委員看到你的邏輯和潛力。

Zyxel 的實習給了我一個很好的「業界視角」，讓我在申請工程導向的 program 時有別的切入點。如果你也有類似的工作或實習經驗，好好利用它。

申請只是第一步，上了才是真正挑戰的開始。期待 2026 秋天在 Urbana-Champaign 繼續更新這個系列！
